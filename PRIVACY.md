# Privacy Policy – LLMent Picker

*Last updated: 9 October 2026 · [Deutsche Fassung unten](#datenschutzerklärung-llment-picker)*

LLMent Picker is a browser extension for Firefox and Chrome. It does not collect, store or transmit any personal data.

**What the extension does with data**

- On your explicit action (toolbar icon, keyboard shortcut, context menu or a click inside the picker) it reads the page element you chose and writes a text reference (URL, CSS selector, optionally selected text) to your clipboard.
- On your explicit action it can take a screenshot of the visible tab, crop it to the chosen element, and save it as a PNG file into your browser's downloads folder or place it in your clipboard.
- On your explicit action it can save the rendered HTML of the chosen element as a file into your browser's downloads folder.
- On your explicit action it can record for five seconds what the page does while you hover and click (CSS rules, transitions, DOM changes, frame timing) and write that protocol to your clipboard.

Everything stays on your device. The extension has no network access, no analytics, no server component and no account. It does not read pages until you invoke it on them (`activeTab` permission) and has no access to other tabs.

**Optional permission** – if you switch on "Also allow elements inside embedded frames from other sites" in the settings, the browser asks you to grant access to all sites. The extension uses it only to run the picker, when you start it, inside frames that a page embeds from another site (for example a contact form). It still reads nothing until you invoke it and sends nothing anywhere. You can withdraw the permission in the settings or in the browser's add-on management at any time.

**Settings** – the preferences (subfolder, "Save as" dialog, screenshot target, CSS context, slim HTML, context-line parts, English output, key hints) are stored in the browser's extension storage; the optional permission above is managed by the browser itself. They contain no personal data and are removed when you uninstall the extension.

# Datenschutzerklärung – LLMent Picker

*Stand: 9. Oktober 2026*

LLMent Picker ist eine Browser-Erweiterung für Firefox und Chrome. Sie erhebt, speichert und übermittelt keine personenbezogenen Daten.

**Was die Erweiterung mit Daten tut**

- Auf Ihre ausdrückliche Aktion (Toolbar-Icon, Tastenkürzel, Kontextmenü oder Klick im Picker) liest sie das gewählte Seitenelement und schreibt eine Textreferenz (URL, CSS-Selektor, optional markierter Text) in Ihre Zwischenablage.
- Auf Ihre ausdrückliche Aktion kann sie einen Screenshot des sichtbaren Tabs aufnehmen, auf das gewählte Element zuschneiden und als PNG-Datei in den Download-Ordner Ihres Browsers legen oder in Ihre Zwischenablage stellen.
- Auf Ihre ausdrückliche Aktion kann sie das gerenderte HTML des gewählten Elements als Datei in den Download-Ordner Ihres Browsers legen.
- Auf Ihre ausdrückliche Aktion kann sie fünf Sekunden lang aufzeichnen, was die Seite beim Hovern und Klicken tut (CSS-Regeln, Übergänge, DOM-Änderungen, Bildrate), und dieses Protokoll in Ihre Zwischenablage schreiben.

Alles bleibt auf Ihrem Gerät. Die Erweiterung hat keinen Netzwerkzugriff, keine Analyse-Funktionen, keine Server-Komponente und kein Konto. Sie liest Seiten erst, wenn Sie sie dort aufrufen (Berechtigung `activeTab`), und hat keinen Zugriff auf andere Tabs.

**Optionale Berechtigung:** Schalten Sie in den Einstellungen „Auch Elemente in eingebetteten Frames fremder Herkunft wählbar machen" ein, bittet der Browser Sie um Zugriff auf alle Websites. Die Erweiterung nutzt ihn nur, um den Picker beim Start auch in Frames laufen zu lassen, die eine Seite von einer anderen Website einbettet (etwa ein Kontaktformular). Sie liest weiterhin nichts, bis Sie sie aufrufen, und sendet nichts. Die Berechtigung lässt sich in den Einstellungen oder in der Add-on-Verwaltung des Browsers jederzeit entziehen.

**Einstellungen:** die Voreinstellungen (Unterordner, „Speichern unter"-Dialog, Screenshot-Ziel, CSS-Kontext, verschlanktes HTML, Bestandteile der Kontextzeile, englische Ausgabe, Tastenhinweise) werden im Erweiterungsspeicher des Browsers abgelegt; die optionale Berechtigung verwaltet der Browser selbst. Sie enthalten keine personenbezogenen Daten und werden mit der Deinstallation entfernt.
